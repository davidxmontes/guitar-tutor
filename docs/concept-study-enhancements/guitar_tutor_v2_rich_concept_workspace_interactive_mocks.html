Rich interactive ConceptWorkspace prototype

Users manipulate real musical controls. Tutor works on the same state.

This version is intentionally more product-like: Circle of Fifths, key and chord-family inspection, scale/root/mode selection, chord quality and voicing selection, and a fully editable progression. The controls are interactive so you can see how user actions and Tutor actions could share one model.

Try the controls. Change keys, scales, chord qualities, progression chords, and selected progression steps. The goal is to demonstrate the actual reusable building blocks—not only simplified interaction cards.
