# Harmony Explorations are branch-local state, not Artifacts

A Harmony Exploration is autosaved branch-local state with no save action, no
Artifact, and no revisions. A Progression idea is a Working Draft that promotes
to a ProgressionArtifact. This asymmetry is deliberate.

A guitarist keeps a progression — "I made this, save it." A harmonic
exploration is working context — "show me A Dorian, what chords belong here,
why does D7 work" — that you re-ask for rather than reopen from a library.
Persistent session state is not the same as a saved Artifact, and only the
second needs naming, a library entry, and revision history.

This makes Develop the single path from exploration to authored music: explore,
audition, develop, author, save. It also collapses the awkward question of
whether opening saved work forks a Branch — only Progression artifacts are
opened, and opening one is not inherently a conversational fork.

If a Harmony Exploration ever grows into something a user clearly wants to name
and reuse independently — a custom harmonic palette for a song, with borrowed
chords and favourite voicings — a HarmonyArtifact can be added then. It is not
manufactured now for symmetry with Progression.
