# Triage labels

| Workflow role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is needed |
| `needs-info` | `needs-info` | Reporter information is needed |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready to implement |
| `ready-for-human` | `ready-for-human` | Requires human implementation or action |
| `wontfix` | `wontfix` | Will not be actioned |

Use the GitHub label in the middle column whenever a workflow skill names a
role from the first column.
