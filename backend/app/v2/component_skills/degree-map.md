# Scale degrees

Connect spelled notes with their degrees; select the characteristic degree when explaining modal color.

Reads: Tonal center, scale, selected degree.

Actions and selection: Select degree and highlight the same pitch class on the fretboard.

Pairs well with: fretboard, circle-of-fifths.

Layout and configuration: Compact wrapping row. labels is notes or degrees. Use either this or scale-staff, not both for the same scale.
