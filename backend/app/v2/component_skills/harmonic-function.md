# Chord roles in a key

Connect Roman numerals and tonic/subdominant/dominant roles to actual chords.

Reads: Active idea, tonal center, selected step.

Actions and selection: Select chord to update editor, diagram and fretboard.

Pairs well with: progression-editor, fretboard.

Layout and configuration: Compact or medium. Without a key invite the learner to set one; do not invent a function label.
