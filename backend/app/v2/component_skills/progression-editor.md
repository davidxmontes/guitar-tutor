# Edit the selected progression chord

Work on one chord in the persistent progression strip. Chord changes, duration, order and physical voicing edits remain deterministic.

Reads: Active idea, selected step, tuning.

Actions and selection: Change root/quality/duration; select a trusted voicing diagram; reorder/remove/add.

Pairs well with: fretboard, harmonic-function. The editor includes the selected chord diagram and Hear action; avoid adding a duplicate focus chord-diagram.

Layout and configuration: Use size small beside a fretboard in a split. Edit chord expands root, quality, duration and voicing controls; beats_per_bar is a positive integer. Playback temporarily drives the visible chord without changing persistent selection.
