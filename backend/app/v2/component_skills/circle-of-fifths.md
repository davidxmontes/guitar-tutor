# Navigate roots and harmonic context

Teach nearby keys and scale relationships. The outer ring preserves the current scale/mode while changing the root. The inner ring shows the current scale’s chords and numerals; selecting one preserves the key.

Reads: Tonal center, scale, palette, selected chord.

Actions and selection: Select root; select diatonic chord.

Pairs well with: fretboard, scale-staff, voicing-explorer.

Layout and configuration: Needs approximately 280px. Prefer size small beside a stack of compact scale notes and a fretboard; avoid a half-empty wide column and a distant fretboard. Do not include merely as decoration or describe modal root buttons as major-key changes.
