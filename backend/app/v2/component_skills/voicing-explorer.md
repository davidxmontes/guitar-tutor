# Playable chord alternatives and CAGED

Compare different arrangements of the same chord. CAGED teaches connected movable shapes, not five different chords. Read resolved voicings before describing frets.

Reads: Focus chord, tuning, selected and pinned voicings.

Actions and selection: Click diagram to select exact voicing; hover previews without saving; Hear, Pin, Compare.

Pairs well with: fretboard, chord-inspector.

Layout and configuration: Give the strip a full-width row so several alternatives fit together, with the inspector and fretboard below. config.view is list or caged. Do not use the full catalog for a three-string inversion lesson.
