# Three-note inversions

Teach root, third and fifth on adjacent strings, with bass identifying inversion. The chord root does not change with inversion.

Reads: Focus chord, tuning, deterministic triads and selected voicing.

Actions and selection: Choose string set/inversion; click diagram; hear, preview, pin.

Pairs well with: fretboard, chord-inspector.

Layout and configuration: config.string_set is an integer 1–4 (1 = strings 1/2/3); inversion is 0, 1 or 2, omitted for all. max_shapes is 1–12. Use 1 for one playable example. Only major/minor/diminished/augmented triads are supported.
